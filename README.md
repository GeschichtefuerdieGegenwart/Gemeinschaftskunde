# Gemeinschaftskunde · Politik-Werkstatt

Digitale Lerneinheiten für Geschichte mit Gemeinschaftskunde (Berufliches Gymnasium, Baden-Württemberg), Hilda-Domin-Schule Herrenberg.

**Einheit 1: Parteien und Wahlen** (J1, BPE 2.1) – fünf Stationen vom Art. 21 GG bis zum Sitzrechner, Stimmzettel des Wahlkreises 260 Böblingen (Bundestagswahl 2025), Positionen wörtlich aus den Wahlprogrammen 2025, Repräsentative Wahlstatistik 2025.

- Start: `index.html` – läuft offline per Doppelklick und über GitHub Pages.
- Technik: statisches HTML/CSS/JS, keine Frameworks, keine externen Dienste, lokale Schriften (OFL), Eingaben nur im localStorage des Geräts.
- Gestaltung und Prüfkette: `DESIGN.md`, `PRODUCT.md`, `BERICHT.md`; eigene Prüfung `tools/pruefen.py`.
- Didaktik: Beutelsbacher Konsens (Überwältigungsverbot, Kontroversität); keine Parteiempfehlung, kein Übereinstimmungswert.

Stand 19.10.2026. Quellen auf der Zusammenfassungsseite.
